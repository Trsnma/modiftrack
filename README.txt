ModifTrack - cara pasang (XAMPP)
1. Salin folder "modiftrack" ke C:\xampp\htdocs\
2. Start Apache + MySQL, buka phpMyAdmin > Import > pilih database.sql
3. Buka http://localhost/modiftrack/
4. Admin awal: admin / Admin#12345  (segera ganti: buat user baru lalu ubah role via SQL, atau ganti hash)
5. Opsional: taruh gambar kendaraan (PNG transparan) di assets/img/hero.png untuk landing page.
Jika password MySQL root Anda tidak kosong, ubah config/koneksi.php.
